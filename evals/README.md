# Behavioral evaluations

This folder is for reproducible agent experiments. **No model-based evaluation has run yet.**

First compare the same task with no skill, then with the current skill, using a fixed model/harness/tools configuration. Capture correctness, decision quality, added complexity, tool calls, tokens, elapsed time, and regressions on low-risk tasks.

See [evaluation policy](../docs/evaluation.md). Static CI explicitly reports `behavior_evaluation: not_run`.
